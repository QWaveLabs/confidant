# Confidant install

If a person arrived here through `CUSTOMER_PROMPT.md`, read
`.agents/skills/confidant-install/SKILL.md` now and follow it. It is the
whole install runbook: the setup questions, the connect list, extracting
and sorting their history, the scheduled agents, and the sandbox and trust
setup. Don't improvise a different flow.

If you're a contributor working on this repository itself rather than
installing it for someone, see `README.md` and `CONTRACTS.md` instead.
